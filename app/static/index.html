    Release Servo

    seconds
    When recording finishes (plus the configured offset), the release servo runs unwind (2000 us) until the shaft rotation sensor has counted 52 rotations (or 60 s elapses as a safety cap), then returns to stop (1500 us). The string spools off the post and the unit floats to the surface.

    Winch (Vertical Profiling)

    Available speeds: Unwind 52 RPM / Wind 52 RPM (bench-calibrated). Same speed used for unwind and wind. Cap: 30 revolutions per leg.
